## 三、为什么做

**问题来源（两个专业看到同一个 bug）：**

从用户侧看：记账 App 装了又删，因为它们**把记账变成了记账**——打开是一堆表格和分类统计，看完只会得出"我又乱花了"这个结论，然后关掉。可学生在花钱的那一瞬间需要的不是月报，是**被拦一下**。

从机制侧看：记账这件事的激励结构本来就是坏的——**成本由用户当场承担，收益却要推迟到月底才结算**，这跟"先存钱后奖励"的经典失效模型一模一样。而宿舍里真正攒下钱去买耳机、去毕业旅行的人，靠的从来不是预算表，是"再攒 X 就够一张门票"这种**具体的期待**。抽象的 ¥8,000 没有推力，具象的"还差 12 笔"才有。

所以我们要做的不是"更好看的表格"，而是**把收益从月底挪到记账的那一秒**。

**我们的想法（四条设计原则）：**

1. **把数字换成人话**：金额必须立刻落到实物和目标上，否则统计只是装饰。
2. **回报要即时**：每天一次盲盒 + 徽章 + 里程碑，让"记了这笔"有当场反馈。
3. **步骤压到 3 步以内**：不填表、不选账户、不强制分类树；目标只有金额必填，名称和截止日期都折叠成选填。
4. **数据是私人的**：纯前端 + IndexedDB，不注册、不登录、不上传，导出功能留备份出口。

## 四、怎么用（评委照做即可，5 步）

1. **打开网址**：浏览器（推荐 Chrome / Edge，手机和电脑都自适应）访问 https://qiantu-v4sx67my80g.qoder.zone ，无需安装与登录。
2. **设个目标**：首页点「设定目标 🎯」，填目标金额（例如 8000）；目标名称、截止日期都是选填 → 顶部立刻出现进度条。
3. **记一笔**：点右下角 ✏️ → 选分类（🍜 餐饮 … ✈️ 旅行，共 24 个）→ 用数字键盘或快捷金额输入 → 顺手点一个心情（😊~😰，可跳过）→ 点「确认记账 🌸」。进度条和当天收支会同步更新。
4. **看换算**：底部切到「💡 值多少」，今天的支出马上变成 ≈ 若干实物；再点「+ 添加」把你想买的东西写进愿望清单（选图标、填价格、打 1~5 星），清单会按重要度排序，并显示"今天消费 ≈ 几个它"。
5. **开盲盒**：切到「🎰 开盲盒」，点一次盲盒（每天一次），看粒子动画和抽到的稀有度。连续记账满 3/7/14/30 天会分别获得 +2%/+5%/+10%/+15% 的稀有概率加成；想留存可以点「保存图片」导出卡片海报。

> 补充两点：**所有数据只存在你当前浏览器的 IndexedDB 里**，清缓存即清空，也可导出 CSV 备份；**删掉一笔支出会同步撤销这笔带来的盲盒结果和里程碑**，所以成就刷不了假。

### 5.2 我们改了什么（改什么、算不算过关由我们定）

- **多目标 → 单目标**：Qoder 第一版做了多目标 + 每目标独立进度，我试用后判断切换成本高于收益，打回改成只保留一个总目标，净储蓄 = 收入 − 支出 自动计入，并定下"删除旧目标后已存金额从 0 重新算"的口径。
- **"约等于" → "≈"**：换算模块原本写"约等于 3.2 个"，我要求改成 ≈ 符号并移到数量前面、单行显示——一个符号比一句话更像人话。
- **打卡防作弊**：原本补记昨天也算连续。我认为这会让人为了数字乱记，改成**只有当天记账才算打卡**；再进一步要求删除支出时同步撤销对应盲盒与成就。
- **里程碑只留 50% 和 100%**：Qoder 给了可配置阈值，我砍掉配置项：50% 在进度条里嵌一枚 🚩，100% 弹庆祝，进度回落时自动撤销不再成立的里程碑。
- **弹窗必须正中间**：连续三版弹窗在宽屏上偏左偏右，我三次打回，最后统一 flex 居中 + 弹窗尺寸一致。
- **对比度与可读性**：黄色标签、稀有标签文字在暖色底上看不清，我要求全部改深色字；并把全局字号放大 12.5%~25%，让网页端不显得像放大版手机屏。
- **表单必填项压到最少**：目标名称改为选填、截止日期折叠成「+ 添加截止日期」，只保留金额必填。
- **风格定调**：ZCOOL KuaiLe 圆润字体 + 马卡龙暖色 + 云朵/星星/花瓣装饰，参考阿柴记账、喵喵记账那一挂的治愈感，但不要宠物养成那种额外负担。
- **验收硬约束**：每轮必须给实测结论和未达标项清单，不确定处先给可运行的最小实现，不允许留 TODO 反问我。

### 5.5 我知道它还不好的地方

- **纯前端本地存储**：换浏览器或清缓存不会迁移数据，所以留了 CSV 导出作为备份出口，但没有多设备同步。
- **内置换算参照物只有 3 个**（鸡蛋 ¥1.5 / 矿泉水 ¥2 / 电影票 ¥40），其余靠你自己在愿望清单里定义——我认为这样反而更贴合"你想要的东西"。
- **盲盒每天一次是硬限制**，用来保证稀缺陷，不是 bug。
